TRUST COMMUNAL — краткая инструкция

1) Как запустить через Python
--------------------------------
1. Установите Python 3.10+ (на ПК для разработки).
2. Откройте командную строку в папке проекта.
3. Установите зависимости:
   pip install -r requirements.txt
4. Запустите программу:
   python main.py

2) Как собрать portable .exe (Windows)
---------------------------------------
Рекомендуется сборка в режиме onedir (надёжнее для переносимости и шаблонов).

1. В командной строке Windows откройте папку проекта.
2. Выполните:
   build_windows.bat
3. Готовая portable-версия появится в папке:
   dist\trust_communal_contract_generator\

Для переноса на другой компьютер копируйте всю папку
"dist\\trust_communal_contract_generator" целиком.

3) Какие папки нельзя удалять
------------------------------
Нельзя удалять (внутри папки с программой):
- templates/   (шаблоны договоров)
- data/        (данные программы)
- generated/   (сгенерированные договоры .docx)
- settings/    (сохранённые реквизиты арендодателя)

Если этих папок нет, программа создаст их автоматически при запуске,
но для сохранённых данных их нужно хранить и переносить вместе с программой.
