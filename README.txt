TRUST COMMUNAL - генератор договоров

1) Запуск через Python
---------------------------------
1. Откройте командную строку в папке проекта.
2. Установите зависимости:
   python -m pip install -r requirements.txt
3. Запустите программу:
   python main.py

2) Сборка portable .exe (Windows)
---------------------------------
1. Запустите файл build_windows.bat (двойной клик).
2. Готовая portable-версия появится в папке:
   dist\trust_communal_contract_generator

3) Какие папки нельзя удалять
---------------------------------
Нельзя удалять эти папки рядом с программой:
- templates   (шаблоны договоров)
- settings    (реквизиты арендодателя)
- data        (служебные данные)
- generated   (готовые договоры .docx)

Важно:
Для переноса на другой компьютер просто скопируйте всю папку
"trust_communal_contract_generator" из dist целиком.
